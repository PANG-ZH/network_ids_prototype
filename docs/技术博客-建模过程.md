# 基于机器学习的网络入侵检测原型系统 —— 建模过程记录

**作者**：庞子灏（北京邮电大学 · 信息安全）  
**时间**：2026.05 – 2026.09

---

## 1. 项目背景

网络入侵检测是网络安全的核心能力之一。传统基于规则的 IDS 难以应对新型攻击和加密流量，机器学习方法能从流量统计特征中自动学习正常/异常模式。

本原型选用公开权威数据集 **CICIDS2017**，构建恶意流量二分类模型，并封装为可实时调用的 API。

## 2. 数据集

- **名称**：CICIDS2017（Canadian Institute for Cybersecurity）
- **内容**：5 天真实网络流量（含 Benign + 多种攻击：DoS、DDoS、PortScan、BruteForce、Web Attack、Bot、Infiltration 等）
- **特征**：CICFlowMeter 提取的 80+ 网络流统计特征（时长、包数、字节数、IAT、包长统计等）
- **处理**：
  - 二分类：BENIGN vs ATTACK
  - 清理 inf / NaN
  - 去除非数值与标识类字段（Flow ID、IP、Timestamp 等）

## 3. 模型选择与训练

### 3.1 Random Forest
- 优点：对特征缩放不敏感、可解释性较好、抗过拟合
- 参数：n_estimators=100, max_depth=20, class_weight="balanced"

### 3.2 XGBoost
- 优点：梯度提升、正则化、高准确率
- 参数：n_estimators=150, max_depth=8, learning_rate=0.1, subsample=0.8

### 3.3 评估指标
- Accuracy、Precision、Recall、F1-Score、Confusion Matrix
- 在二分类场景下，两者均可稳定达到 **99%+** 准确率

## 4. 工程落地

1. 使用 `joblib` 持久化模型与 StandardScaler
2. Flask 封装 `/predict` 接口，支持单条/批量特征输入
3. 返回预测标签 + 攻击概率，便于后续阈值联动

## 5. CodeBERT 扩展尝试

尝试使用 Microsoft CodeBERT 对 HTTP 请求 Payload 进行恶意文本分类（作为原型验证）。  
由于流量特征模型已足够强，且 CodeBERT 需要额外 GPU 资源与文本标注数据，本阶段仅完成可行性验证，未正式上线。

## 6. 结果与体会

- 树模型在表格型流量特征上表现优异，训练与推理速度都较快。
- 真实部署时需注意：特征提取工具版本一致性、概念漂移、对抗样本。
- 后续可结合在线学习、威胁情报与多模型融合进一步提升。
